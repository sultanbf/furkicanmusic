🔌 Bağlantı Modu

API anahtarları ve adresleri sabittir (koda gizli olarak gömülüdür) — burada yalnızca üretimin hangi yol üzerinden yapılacağı seçilir.
🔗 n8n Webhook
Kendi n8n kurulumunuz varsa en kolay yol. Site, prompt'u n8n akışınıza POST eder; akış, Suno ile iletişimi sizin için yönetir.
🌐 Suno API Servisi
Üçüncü parti Suno API sağlayıcısı (API key gömülüdür). Site doğrudan üretim yapar ve sonucu otomatik indirir.

🔗 n8n Webhook

Webhook adresi sabittir (anahtar koda gömülüdür). Arayüzden değiştirilemez; değiştirmek için assets/js/keys.js dosyasındaki EMBEDDED_N8N.webhookUrl değerini düzenleyin.
n8n'de Webhook düğümü POST olarak aktif olmalı ve "Respond to Webhook" açık olmalıdır. CORS engeli için server/server.js proxy'si (npm start) veya proxy URL gerekir.

🌐 Suno API Servisi

Sağlayıcıyı seçin. API base URL ve anahtar otomatik olarak koda gömülü olanlardan okunur.
Önemli: Base URL sağlayıcıya göre otomatik belirlenir. Anahtar assets/js/keys.js içindeki EMBEDDED_KEYS bölümüne gömülüdür. Proxy için npm start ile server'i çalıştırın (Netlify'da gerekmez).
