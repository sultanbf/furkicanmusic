🔌 Bağlantı Modu

Suno'nun resmi bir public API'si yoktur. İki yöntemden birini seçin.
🔗 n8n Webhook
Kendi n8n kurulumunuz varsa en kolay yol. Site, prompt'u n8n akışınıza POST eder; akış, Suno ile iletişimi (ücretsiz hesap dahil) sizin için yönetir.
🌐 Suno API Servisi
Üçüncü parti Suno API sağlayıcısı (sunor.cc, songapi.dev vb.). API key alır, site doğrudan üretim yapar ve sonucu otomatik indirir.

🔗 n8n Webhook Ayarları

n8n'de Webhook düğümü oluşturun (POST, "Respond to Webhook" açık) ve URL'yi buraya yapıştırın.
n8n'de CORS açılmamışsa tarayıcı webhook'a doğrudan bağlanamaz. Sunucuyla gelen proxy (server/server.js, npm start) bu engeli aşar: istek önce kendi sunucuna gider, sunucu n8n'e bağlanır. n8n'de Options → Allowed Origins (CORS) → * yaparsanız bu alanı boş bırakabilirsiniz.
n8n akışınız şu JSON'u alır:
Akışta Suno'yu çağırmak için (opsiyonel): self-hosted gcui-art/suno-api veya sunor.cc API'sini HTTP Request düğümüyle kullanabilirsiniz. Dönen audio_url'yi Webhook Response olarak geri gönderin.

🌐 Suno API Servisi Ayarları

Önerilen sağlayıcılar: sunor.cc (25 ücretsiz kredi, Google ile kayıt) ve songapi.dev (ücretsiz sandbox). Key'i ilgili sitenin dashboard'undan alın.
API çağrıları tarayıcıdan yapılamaz (CORS engeli) — bu yüzden varsayılan olarak projeyle gelen server/server.js proxy'si (http://localhost:3000) kullanılır ve API key gizli kalır. Netlify'da: bu alanı boş bırakın — çağrılar otomatik olarak Netlify Functions'a (/api/...) gider. Önemli: Sağlayıcı ile Base URL eşleşmeli: sunoapi → https://api.sunoapi.org, sunor → https://sunor.cc/api/v1 vb. Proxy çalışmıyorsa server klasöründe npm start çalıştırın.

📖 Hızlı Kurulum Rehberi

Seçenek 1 — n8n ile (ücretsiz Suno hesabı):
1. n8n'de Webhook düğümü ekleyin (POST).
2. HTTP Request düğümüyle sunor.cc veya self-hosted suno-api'ye bağlanın.
3. Yanıttaki audio_url'yi "Respond to Webhook" ile geri döndürün.

Seçenek 2 — Suno API ile (en kolay):
1. sunor.cc'ye Google ile kaydolun, 25 ücretsiz kredi alın.
2. Dashboard'dan API key oluşturun.
3. Bu sayfaya key'i ve base URL'yi girin, kaydedin.
4. Gerekirse server/server.js proxy'sini çalıştırın (key'i gizli tutar).
